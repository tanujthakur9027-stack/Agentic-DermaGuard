Clinical Decision Criteria & Six-Agent Consensus Policy

Mathematical cutoffs, safety veto triggers, and deterministic coordinator rules.

Agent 1: Quality Gatekeeper Criteria

Evaluates Laplacian variance (sharpness), histogram entropy (lighting), HSV V-channel glare, and centering edge ratio.

  • Sharpness < Cutoff: Triggers Blur Defect flag
  • Entropy < Cutoff: Triggers Illumination Defect flag
  • Glare Score < Cutoff: Triggers Specular Void flag
  • Overall Quality < 50 or ≥2 Defects: Short-circuits to RE_IMAGE

Agent 3 & 4: ABCD Visual Cues & Patient Context

Maps lesion contour and computes compactness \(P^2 / 4\pi A\), radial distance variance, and asymmetry index across horizontal/vertical folds.

  • Border Compactness > 1.6: Flagged as Irregular Border
  • Asymmetry > 0.40: Flagged as Marked Asymmetry
  • Context Age > 65 + Scalp/Face Site: High Risk demographic prior

Agent 5: Safety Sentinel & Veto Rules

Cross-examines diagnosis with visual cues and patient context to prevent dangerous automated discharges.

  • Diagnosis = Benign, but Irregular Border / Asymmetry: VETOS AUTO_TRIAGE
  • Diagnosis = Benign, but High-Risk Context (Elderly scalp/face): VETOS AUTO_TRIAGE
  • Sub-threshold Malignancy Prob (Mel + BCC > 28%): VETOS AUTO_TRIAGE

Agent 6: Coordinator Master Policy

Applies strict precedence order to determine final action and explanation:

  • IF Quality = RE_IMAGE → Action = RE_IMAGE (Preserving diagnosis)
  • ELSE IF Predicted Class in {mel, bcc, akiec} OR Safety Veto → Action = REFER
  • ELSE IF Confidence ≥ Auto Threshold AND Clear Safety → Action = AUTO_TRIAGE
  • ELSE → Action = REFER (Conservative uncertainty escalation)
