Six Specialized Roles & Clinical Decision Architecture

Why multi-agent? Standalone neural networks produce unverified predictions without capture-quality checks, clinical morphometry, or patient demographic safeguards. DermaGuard separates perception, diagnosis, morphometry, patient context, safety auditing, and coordination into 6 collaborative specialist agents.

Agent 1: Image Quality Agent

Acts as the initial gatekeeper. Rejects compromised captures before diagnostic misclassification occurs.

• Sharpness: Laplacian \(\sigma^2\) + Tenengrad \(G^2\)
• Lighting: Shannon Entropy \(H = -\sum p \log_2 p\)
• Glare: HSV Value Saturation \(V > 240\)
• Centering: Active field vs. outer border clipping
Agent 2: Diagnosis Agent

Predicts one of the 7 permitted HAM10000 disease codes (`mel`, `nv`, `bcc`, `akiec`, `bkl`, `df`, `vasc`).

• Backbone: EfficientNet-B0 (1280-dim representations)
• Certainty: Top-1 vs. Top-2 separation margin
• Cumulative Risk: \(P(\text{mel}) + P(\text{bcc}) + P(\text{akiec})\)
• Rule: Always predicts even if image is RE_IMAGE
Agent 3: Lesion Analysis Agent

Extracts dermatological ABCD structural cues independently of CNN probability weights.

• Asymmetry (A): 0 to 2 reflection non-overlap axes
• Border (B): 0 to 8 octants & compactness \(P^2/4\pi A\)
• Color (C): 1 to 6 dermoscopic pigment shades
• TDS Formulation: \(1.3A + 0.1B + 0.5C + 0.5D\)
Agent 4: Reasoning / Context Agent

Incorporates patient demographics and anatomical site priors into clinical risk assessment.

• Age: Solar elastosis & incidence stratification
• Sex: Male head/neck/trunk risk predisposition
• Site: Chronic UV (head/neck) vs. intermittent (torso)
• Missing Fields: Traceable flags & confidence penalty
Agent 5: Safety Agent (Sentinel)

Enforces 'Primum Non Nocere'. Audits diagnosis against ABCD morphometry and patient context to veto unsafe decisions.

• Rule S1: Malignant class code → Immediate Veto
• Rule S2: Residual Malignancy Prob ≥ 28% → Veto
• Rule S3: Benign Dx vs. High TDS → Structural Veto
• Rule S4: Benign Dx vs. Elderly UV Site → Context Veto
Agent 6: Coordinator Agent

Applies a deterministic decision matrix to synthesize all signals into a finalized disposition.

• Action 1: RE_IMAGE (Quality inadequate)
• Action 2: REFER (Malignancy, Veto, Uncertainty)
• Action 3: AUTO_TRIAGE (Verified Benign)
• Traceable Chain: Complete evidence string
