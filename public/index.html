Clinical Threshold Criteria & Decision Rules

Explicit mathematical rules governing agent decisions and multi-agent consensus triage.

1. Image Quality Agent Rules

  • • Blur Criterion (τblur = 40): Evaluates Laplacian variance $\sigma^2 = \text{Var}(\nabla^2 I)$. If score < 40, edge frequencies are degraded.
  • • Illumination Criterion (τlight = 40): Evaluates grayscale histogram entropy $H = -\sum p_i \log_2(p_i)$. If score < 40, underexposure or contrast loss is present.
  • • Specular Glare Criterion (τglare = 70): Identifies saturated overexposed pixels ($V > 240$ in HSV). Glare > 15% triggers rejection.
  • • Centering Criterion (τoccl = 50%): Computes ratio of central quadrant Sobel edges to total border edges. Lesions cut off by borders fail.
  • • Re-Image Gate: If overall quality < 50 OR 2+ defect criteria trigger $\rightarrow$ outputs RE_IMAGE.

2. Consensus Decision Engine Rules

  • • Malignancy Referral Trigger (τmalig = 35%): If predicted class is in {Melanoma, BCC, AKIEC} OR combined malignant probability ≥ 35% $\rightarrow$ outputs REFER.
  • • Diagnostic Uncertainty Trigger: If predicted class is Benign (Nevus, BKL, DF, Vascular) but diagnostic confidence < 70% $\rightarrow$ outputs REFER.
  • • Quality Caution Referral Trigger: If image quality was borderline (ACCEPTABLE_WITH_CAUTION), automatic triage is disabled $\rightarrow$ outputs REFER.
  • • Automated Triage Criterion: ONLY when image quality is validated AND predicted class is Benign AND confidence ≥ 70% $\rightarrow$ outputs AUTO_TRIAGE.
